# Foundry releases

Public desktop installers for [Foundry](https://iamgenesis.ai/foundry).

The application source stays in the private `IAMGENESISAI/foundry` repository. This repository only receives signed release assets:

- macOS `.dmg` (Apple Silicon and Intel)
- Windows `*-setup.exe`
- Linux `.deb`, `.rpm`, and `.AppImage` when the Linux runner produces them
- `latest.json` for the in-app updater

Download the latest version from [iamgenesis.ai/foundry](https://iamgenesis.ai/foundry) or from [Releases](https://github.com/IAMGENESISAI/foundry-releases/releases).
